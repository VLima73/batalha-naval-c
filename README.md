# Jogo de Batalha Naval em C

Projeto desenvolvido para o Tema 5 – Jogo de Batalha Naval, da disciplina de Engenharia de Software.

## Descrição
O programa simula um tabuleiro de Batalha Naval 10x10 utilizando vetores, matrizes,
estruturas de repetição e condicionais em linguagem C.

O projeto contempla:
- Posicionamento de navios horizontais, verticais e diagonais;
- Validação de limites do tabuleiro;
- Implementação de habilidades especiais (Cone, Cruz e Octaedro);
- Exibição do tabuleiro no console.

## Como executar
gcc batalha_naval.c -o batalha
./batalha
